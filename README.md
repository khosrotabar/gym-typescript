# Gym Club — React TypeScript Landing Page

A responsive gym and fitness landing page built with React and TypeScript.

This project was created as a frontend practice project to improve component structure, responsive layouts, TypeScript usage, and clean UI implementation.

## Live Demo

https://gym-typescript-tau.vercel.app/

## Overview

Gym Club is a modern fitness landing page concept designed for gyms, fitness studios, and personal trainers.

The main goal of this project was to build a clean, responsive, and user-friendly interface using React and TypeScript.

## Features

- Responsive landing page design
- Modern fitness-focused UI
- Reusable React components
- TypeScript-based development
- Clean section-based layout
- Deployed on Vercel

## Tech Stack

- React
- TypeScript
- CSS / modern styling
- Vercel

## What I Practiced

- Building reusable UI components
- Structuring a frontend project
- Working with TypeScript in React
- Creating responsive layouts
- Deploying a frontend project to Vercel
